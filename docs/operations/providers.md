# Provider configuration and trust boundaries

No live credentials have been configured or tested in this repository. Local OTP, age assurance, moderation, entitlement overrides and notifications are explicitly mocks. Production mode must be false for all mock flags. Never put private values in chat, Git, an Xcode setting or a browser environment variable.

| Integration | Required configuration | Operation and verification |
|---|---|---|
| Email (Resend) | EMAIL_API_KEY, EMAIL_FROM | Verify sending domain, restrict key; send and receive an actual OTP. HTTPS api.resend.com. |
| SMS (Twilio) | SMS_ACCOUNT, SMS_TOKEN, SMS_FROM | Provision sender, compliance and spend limits; verify E.164 OTP delivery. HTTPS api.twilio.com. Raw Basic credentials may require a normal Workers Secret, not a proxy placeholder. |
| Apple login | APPLE_BUNDLE_ID, Apple developer capability | Configure App ID and Sign in with Apple; server verifies JWKS issuer/audience/nonce/age and consumes nonce. HTTPS appleid.apple.com. Test relay and non-relay accounts. |
| Adult assurance | AGE_JWKS_URL, AGE_ISSUER, AGE_AUDIENCE | Jurisdiction-approved independent provider signs short-lived JWT with sub=Zyra UUID, over_18=true, unique jti, iat and exp. Provider must bind its ceremony to the authenticated account. Store outcome/reference only. Integrating its hosted ceremony remains external work; a birthdate alone never activates production. |
| Image processing | MEDIA_PROCESSOR_URL, MEDIA_PROCESSOR_TOKEN | Private HTTPS endpoint receives image bytes, must fully decode HEIC/JPEG/PNG, enforce decoded pixel limits, strip metadata, re-encode bounded JPEG/PNG. Worker rechecks signature/structure and strips metadata. Production fails closed without it. Contract is not a delivered hosted processor. |
| Moderation | MODERATION_URL, MODERATION_TOKEN | Private HTTPS endpoint receives processed bytes, returns {verdict: approved\|rejected\|review}. Must cover explicit/violent/abuse content and provider limitations. Review remains pending for a human. Queue retries at most three times then DLQ. Local mode autoapproves valid uploads and is not an abuse detector. |
| APNs | APNS_KEY, APNS_KEY_ID, APNS_TEAM_ID | Workers Secret containing P8 key, topic matches bundle. Sandbox/production endpoints api.sandbox.push.apple.com and api.push.apple.com. Test actual physical-device delivery, quiet hours and revocation. |
| Admin | ACCESS_TEAM, ACCESS_AUDIENCE, ADMIN_ROLES | Configure Cloudflare Access app, MFA identity-provider policy, short sessions; map exact verified emails to support/moderator/operations/finance/super_admin in private JSON. Worker verifies Access JWT rather than trusting email headers. Protect the admin host and API admin paths at Access too. |
| Purchases | PURCHASE_VERIFIER_URL, PURCHASE_VERIFIER_TOKEN | Private authenticated HTTPS URL to the supplied Node Apple verifier. Deploy behind TLS and network restrictions. The Node listener binds loopback; use a trusted local reverse proxy. Populate its config from .env.example, obtain Apple root certificates from https://www.apple.com/certificateauthority/, pin/review their fingerprints and mount read-only. The SDK enables online OCSP checks. Provision App Store Server API credentials, Sandbox app/account and Notification V2 endpoint. No Xcode-test receipt may unlock a production entitlement. |

Use `wrangler secret put NAME --config .wrangler/deploy.staging.json` from a trusted terminal after resource rendering; enter values securely. For admin configure API_BASE_URL, ADMIN_PUBLIC_ORIGIN and ANVAYA_LOCAL_ADMIN=false in its environment and Cloudflare Access on its hostname. Server-only values are never NEXT_PUBLIC variables.

For restricted egress, add only the destinations for enabled integrations: the table's hosts, the actual configured age/media/moderation/verifier hosts, `<team>.cloudflareaccess.com`, App Store API `api.storekit.itunes.apple.com` / `api.storekit-sandbox.itunes.apple.com`, and the Apple certificate-chain OCSP hosts required by the current certificates. Confirm from official provider configuration; do not disable online revocation/TLS checks. There is no reason to request production credentials to use the local free workflow.

Before asking for any credential, inspect configured binding names and presence only. Reuse platform GitHub HTTPS proxy authentication; lack of GH_TOKEN does not imply missing Git access.
